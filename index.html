About

Agent Ecosystem is a personal network of AI agents that do real work — handling tasks, automating workflows, and collaborating with each other. Instead of one assistant doing everything, specialized agents focus on what they're best at and hand off work between them, so I can spend less time on busywork and more time on what matters.

Each agent is scoped to one job — reading files, browsing the web, writing code — and a coordinating layer routes tasks to whichever agent fits, then merges their results back into one workflow.
